# OverWork
A framework for services and controllers, heavily inspired by [Knit](https://github.com/Sleitnick/Knit).

For necessities and dependencies:
1. You'll need a folder placed in `ServerScriptService` named 'Services' and a folder in `ReplicatedStorage` named 'Controllers'.
2. You'll need a Signal module placed within a folder in `ReplicatedStorage` named `Packages`. Most Signal modules should work, but the framework is made with [sleitnick's Signal module](https://github.com/Sleitnick/RbxUtil/tree/main/modules/signal).

Once everything is set up, you simply require the module once from the server and once from the client, then you're good to go.
